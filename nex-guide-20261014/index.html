02 ／ 予約手順

出発前に、特急券を予約。

用意するものは、自分のえきねっとアカウント・登録するクレジットカード・スマホ。必要なら同行者に画面操作を手伝ってもらおう。

えきねっとを開く ↗
  1. 自分のアカウントでログイン。同行者のアカウントで、自分1人分だけを予約しないでね。
  2. 「JRきっぷ」で、この条件を検索。
    乗車日2026年10月14日（水）
    出発駅空港第2ビル
    到着駅大船
    出発時刻の目安12:40ごろ
    人数1人で乗るなら、大人1人
    同行者も同じ列車で帰るなら、人数・行き先を一緒に確認。
  3. 12:49発「成田エクスプレス22号」を選ぶ。到着が大船14:33の経路を選ぼう。普通車の指定席でOK。
  4. 「在来線チケットレス特急券」を選ぶ。きっぷの種類の選択が出たら「その他のきっぷ」へ。Suicaで乗る今回は「えきねっとQチケ」は選ばない。
  5. 乗車券は「申込まない」。運賃は当日Suicaで払うので、えきねっとでは特急券だけ買う。
  6. 座席を選び、カードで支払う。日付・駅・列車・人数・商品名・金額を見直してから申込みを完了。特急料金は予約画面で確認してね。
  7. マイページで予約完了を確認。列車名・発車時刻・号車・席番号を確認。乗車当日も、ログインして申込履歴の詳細を開ける状態にしておこう。
紙の特急券の受け取りも、Suica番号の登録も不要。
Suicaは普段どおり改札にタッチ。特急券の確認を求められたら、スマホの申込履歴詳細を見せるよ。

画面の名前や並びは変わることがあります。「特急券だけ・在来線チケットレス・大船まで」が最終確認のポイント。

03 ／ 当日の動線

着いたら、まず駅の近くへ。

11:40　成田到着予定降機して、預けた荷物があれば受け取る。第3ターミナル1階の到着ロビーへ。

荷物を受け取ったら　移動開始無料バスか徒歩で、第2ターミナル地下1階の空港第2ビル駅へ。

12:30ごろ　JR改札付近が目標ここまで着いていれば、トイレや飲み物・軽食を検討。買い物は短めに。

12:35〜12:40ごろ　改札・ホームへSuicaの残高を確認し、JR改札にタッチ。予約した号車の乗車位置へ向かう。

12:49　22号が発車予約した席に座って、大船まで。食事は車内でゆっくりでも大丈夫。

到着予定と列車の発車時刻以外は、このガイドの行動目安です。降機・荷物受け取り・移動にかかる時間は、当日の状況によって変わります。

第3ターミナル → 空港第2ビル駅

荷物が重い・歩く負担を減らしたい

無料連絡バス

  1. 1階到着ロビーの北口1から外へ。
  2. 2番・3番のターミナル連絡バス乗り場で、表示と係員に「第2ターミナルへ行くバス」を確認。
  3. 第2ターミナルで下車。乗車時間は約3分。
  4. 赤い通路と「鉄道・駅」の案内に沿い、地下1階へ。

約3分はバスに乗っている時間だけ。待ち時間と、降りてからJR改札・ホームまでの移動が別に必要です。

歩ける・バスを待ちたくない

徒歩の連絡通路

  1. 1階到着ロビーの北口2から外へ。
  2. 赤い通路の先、右奥へ。左側のエスカレーターで2階へ上がる。
  3. 館内を通り、第2ターミナルへの連絡通路を進む。
  4. 第2ターミナル側で1階へ下り、さらに地下1階へ。鉄道の案内を目印に。

空港の鉄道案内は駅と第3ターミナルを徒歩約10分としています。荷物・歩く速さ・ホームまでの移動を考え、このガイドでは15〜20分以上の余裕を見ます。

時間が少ないときは、無理して急がない。
バスがすぐ来るか確認し、待つなら徒歩と比較。12:30を過ぎても第3ターミナルにいるなど、余裕が少なければ後の列車へ変更を検討しよう。

スーツケースが大きいときはエレベーターの案内を探してね。場所が分からなければ、空港の係員に聞こう。

動線の根拠：無料バスの乗り場・乗車時間 ／ 空港公式の徒歩目安 ／ 国内線到着の流れ

駅に着いたら

  1. 「JR線」の改札へ。京成線・スカイライナーの改札とは別。同じ物理Suicaを入場から北鎌倉の出場まで使う。
  2. 発車案内と予約を照らし合わせる。22号・12:49発・予約した号車と席番号を確認。ホームでも大船行きの車両か確かめよう。
  3. 大船まで、予約した車両のまま。東京で新宿行きと分かれるので、別の号車へ移動しない。大船行きの指定席なら東京で乗り換えは不要。
  4. 大船で降り、改札を出ずに乗り換え。横須賀線の鎌倉・逗子・久里浜方面へ。目安は7・8番線だけれど、当日の表示を優先してね。
  5. 北鎌倉は次の駅。北鎌倉に停まる列車を確認して乗車。普通車なら追加の特急券は不要。北鎌倉で降り、Suicaをタッチして出場。

05 ／ 遅延時対応

遅れそうなら、
予約を変更。

22号の変更は、12:49より前に完了させる。
飛行機の遅れや荷物待ちで間に合わないと分かったら、通信できる場所で早めに。12:40ごろを、自分の判断・操作の目安にしよう。

① まだ予約した列車の発車前

えきねっとにログイン → マイページの該当予約 → 申込内容の確認・変更 → 予約内容を変更 → 後の大船行きを検索。

変更先の時刻・料金・号車・席を確認し、変更完了まで進める。最後に履歴が新しい列車へ変わったか見よう。

同じ在来線チケットレス特急券への変更は、予約した列車の時刻表上の発車時刻まで。空席が必要です。列車自体が遅れていても、操作期限が延びると考えないでね。

② もう12:49を過ぎてしまった

JR改札の係員に、予約詳細を見せて相談。通常の在来線チケットレス特急券なら、当日・予約区間内の後続の成田エクスプレスの空いている席を使える扱いがあります。

ただし新しい指定席が確保されるわけではありません。その席を予約した人が来たら譲ります。元の席番号で後の列車に座らないでね。

発車後はネットでの変更・払戻はできません。グリーン車など条件が異なる場合も、予約商品を係員と確認してから乗ろう。

③ 列車が運休・満席／操作に困った

走らず、JR係員に「北鎌倉へ帰りたい」と相談。後の大船行きや、利用できる普通・快速列車の経路を確認しよう。

同行者にも画面を見てもらってね。取消・払戻には手数料がかかる場合があります。列車運休などJR側の事情は、通常の乗り遅れと扱いが異なるため案内に従おう。

06 ／ 注意点

出発前の確認リスト。

  • 物理Suicaを持つ。運賃分の残高を確認し、足りなければ駅でチャージ。特急料金はSuicaから引かれない。
  • スマホを充電。当日に自分のアカウントでログインできるか確認。充電器・モバイルバッテリーがあれば安心。
  • 予約は「空港第2ビル→大船」。「成田空港駅」は第1ターミナル側。北鎌倉にはN'EXは停まらない。
  • 指定された号車と席を使う。大船行きと新宿行きがあるので、車両の行き先表示も見る。
  • 予約画面を提示できるようにする。スクリーンショットは自分用の控えに。係員への提示はログインした申込履歴詳細が基本。
昔の「35％引き」「100円引き」は今回の前提にしない。
成田エクスプレスのトク割は2026年9月30日乗車分で終了。10月1日以降の購入は、通常のチケットレス特急券も通常特急料金と同額です。
