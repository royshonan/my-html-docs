# Getting Started
HTMLドキュメントをNotionに埋め込むためのリポジトリです。

## 必要条件
特になし

## セットアップ
1. リポジトリのクローン
   ```bash
   git clone https://github.com/royshonan/my-html-docs.git
   cd my-html-docs
   ```

2. ブラウザでHTMLファイルを開く
   - `layer_thinking_visual.html` をブラウザで開いて閲覧

## ディレクトリ構成（抜粋）
- `/docs` … ドキュメント置き場
- `/` … HTMLファイルの置き場

## 次のステップ
- 新しいHTMLドキュメントを追加する場合は、ルートディレクトリに配置
- ドキュメントを更新する場合は、`docs/` フォルダにMarkdownファイルを追加
